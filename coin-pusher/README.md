# 大魔术师 · R7 叠币剧场

双击本目录 `index.html` 离线运行。页面右上角显示 **R7**。无需服务器、CDN、fetch 或 ES Module。保留本地 Matter.js **0.19.0**。

## 操作

- **START / 空格**：投一枚游戏币，台面点击不会投币。
- **雨刷按钮 / W**：开始摆动「11」双杆，再按一次锁定角度；币从两杆中间出。
- **P**：暂停 / 继续，后台切换也会暂停，不会补算离开时的时间。
- **音效**：可开关。

## SPIN 与出币

- 命中币斗，当前转盘之外最多缓存 **4 次**，右侧显示剩余数和四格指示灯。
- **转盘转动时允许投币和继续命中 SPIN**。
- **中奖提示、自动出币时禁止玩家投币及 SPIN 感应**。模型和按钮/空格键共用锁定条件。
- 待开奖机会原样保留，出奖结束后继续。未中奖不锁定投币。
- 奖励币不会触发额外 SPIN；出奖期间已在场玩家币也不能产生新机会。
- 中奖 100 枚就从顶部投币口发出 100 枚；不会把中奖金额乘以 0.5。台面已满或入口被占时等待，欠币不丢失。
- 只有越过正面收币沿才增加余额，两侧暗槽和前沿两侧通道回收的币不返还。

## 台面和底分

雨刷末端到第一排钉子留有约 90px 自由落币距离。6 排交错钉子参与实际碰撞。经过图案通道时，对应底分 +1。正中央投币有居中分布趋势，但不人为强制每个落点；不声称严格正态分布。

下层是 Matter.js 碰撞加支撑高度的 **2.5D** 叠币模拟：上层币随支撑币移动，支撑移开后落下；不是三维刚体引擎。台面最多 150 枚。

普通横线 = 底分 ×3；普通斜线 = 底分 ×2。魔术师上/中/下排分别对应 JP2/JP1/JP3，整盘相同为 ALL。小游戏倍率是本项目可配置模拟值，不声称与实体机后台一致。

## 验证

```bash
npm test
```

无需安装 Electron 即可运行逻辑、物理与输入接线测试。涵盖队列上限、转动可投币、中奖锁定、出完恢复、暂停、顶部出币、侧口、叠币支撑和离线脚本引用。

100 枚全额出币的五组固定随机种子模拟，正面回收 14～27 枚，暗槽回收 62～71 枚，其余仍在台面。结果依赖原有币堆与落点，这不是每一局返还上限保证。详见 `design/R7_CHANGELOG.md`。
