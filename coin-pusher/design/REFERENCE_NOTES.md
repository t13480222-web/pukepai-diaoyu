# 《大魔术师》实机参考记录

参考页面：

<https://www.tonlly.com/product/ae/mgas/635.html>

## 从页面确认的结构

- 实机是绿色三联机台，每个工位有独立的玻璃台面、主屏、雨刮控制和底部出口。
- 顶部是金色发光灯箱，中心写“大魔术师”，两侧是戴高礼帽的魔术师角色和舞台装饰。
- 游戏主屏使用红色舞台幕布、金色边框和 JP1 / JP2 / JP3 / ALL 奖励栏。
- 每个工位下方有绿色机身、投币口和帽子造型的装饰/出口区域。
- 机台不是纯蓝色科技风，主色是绿色、金色、红色和紫色。

## 从玩法说明确认的循环

- 代币投入后，需要调节雨刮角度改变落点。
- 代币经过钉板区域，玩家需要预判移动中的币斗。
- 代币落入币斗后进入奖励结算。
- 页面还描述了“叠叠乐”小游戏：最多 6 次机会，根据图案累计分数结算；相同图案累计到 6 个时可以提前结算。
- 奖励不是直接退回硬币，而是通过机器下方出口领取彩票。
