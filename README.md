# 扑克牌钓鱼

## 本地运行

```bash
npm start
```

浏览器打开 http://localhost:3000 。同一 WiFi 下，手机访问运行电脑的局域网地址，例如 `http://192.168.1.20:3000`。

## 规则原型

- 54 张牌，双方各 27 张，玩家不知道自己的牌。
- 轮到玩家时由服务器随机抽取一张并放到桌面。
- 最新牌与前一张同点数时，或最新牌为 J/大小王时，出现抢铃机会。
- 抢铃成功者收牌并继续出牌；无人抢铃后轮到另一位。
- 按错铃按 1、2、3 张递增惩罚，给对手，封顶 3 张。
- 时间到或一方牌组耗尽后比较牌数，胜者翻三选一奖励卡。
